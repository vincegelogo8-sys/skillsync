# Account registration has moved to Admin

Public registration is disabled. Students and Faculty receive accounts created
by Admin and log in with the email and initial password Admin provides.

Admin opens **Accounts > Create Account**, selects Student or Faculty, fills in
the name/email/password, and saves. Creating accounts does not log the Admin out.
There is no public role selector and no Admin option in the account-creation form.

See [Admin account creation](admin-account-creation.md) for setup, full source
links, validation rules, and testing instructions. This replaces the previous
public Student/Faculty/Admin registration instructions.
